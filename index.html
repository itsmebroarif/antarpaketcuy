Surat Aero: Kurir Asri — prototipe M0+M1.
Game kurir santai bergaya Frutiger Aero / Windows 7 Aero. Seluruh dunia, bangunan, NPC, dan musik dibuat 100% prosedural saat berjalan — tidak ada aset pihak ketiga, jadi bebas masalah lisensi. Estetika kaca Aero dibuat murni dengan CSS dan shader.

Kontrol desktop: mouse + WASD, Shift dorong, S rem, Spasi lompat, E aksi, C kamera, M peta, Esc menu.
Android: joystick kiri, geser kanan untuk melihat, tombol Dorong/Rem/Lompat/Aksi. Auto-cruise aktif secara default.

Dibuat dengan Three.js. Alur antar-map, kendaraan, dan interior menyusul pada milestone berikutnya.
